## 📚 About The Course

This repository follows a "100 Days of Code" style curriculum, covering fundamental to advanced Python concepts:

- **Basics**: Syntax, Variables, Data Types, Typecasting, Input/Output.
- **Control Flow**: Conditionals, Loops, Break/Continue statements.
- **Data Structures**: Lists, Tuples, Sets, Dictionaries.
- **Functions**: Arguments, Recursion, Lambda Functions, Map/Filter/Reduce.
- **Object-Oriented Programming (OOP)**: Classes, Objects, Inheritance, Polymorphism, Encapsulation, Magic Methods.
- **File Handling**: Reading/Writing files, `os` and `shutil` modules.
- **Advanced Topics**: Exception Handling, Virtual Environments, Regular Expressions, AsyncIO, Multithreading, Multiprocessing.

## 🏁 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/KankonNil007/Python-Course.git
   ```
2. **Navigate to a project directory**:
   ```bash
   cd Completion-Projects/Quiz-App
   ```
3. **Run the application**:
   ```bash
   python main.py
   ```
   _(Note: Check individual folders for specific `main.py` or script names)_
