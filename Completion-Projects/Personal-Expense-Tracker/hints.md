# Personal Expense Tracker

### 🖥 UI (Command Line):
```
========== Expense Tracker ==========
1. Add Income
2. Add Expense
3. View Balance
4. View History
5. Exit
-------------------------------------
Enter your choice: 
```

### 🧠 Features:

- Save each transaction (type, amount, note, date)
- Show balance by summing incomes - expenses
- View history in a nice format

### 💡 Hints:

- Use open() to read/write to a file (transactions.txt)
- Use datetime.now() to save current date
- Use string formatting to keep things aligned
- Store each entry as a line in the file
