# Reminder App

### 🖥 UI (Command Line):
```
====== Water Reminder App ======
Enter reminder message: Drink Water
Remind me in how many seconds? 10

Reminder set! Waiting...

🔔 Reminder: Drink Water!
```

### 🧠 Features:

- Take a message and time from user
- Wait for that time
- Show a pop-up or terminal message

### 💡 Hints:

- Use input() to get time/message
- Use time.sleep(seconds) to wait
- Use print() or plyer.notification (optional library)
- Optional: loop for multiple reminders
