# To-Do List Manager

### 🖥 UI (Command Line):
```
========= To-Do List =========
1. Add Task
2. Mark Task as Complete
3. View Tasks
4. Delete Task
5. Exit
------------------------------
Enter your choice: 
```

### 🧠 Features:

- Add tasks to a file
- Show pending and completed tasks separately
- Mark tasks as completed
- Delete tasks

### 💡 Hints:

- Store each task in a text file (todo.txt)
- Use a special marker for completed tasks, like:
```
[ ] Study for exam
[x] Call mom
```
- Use with open(...) and readlines() to process tasks
