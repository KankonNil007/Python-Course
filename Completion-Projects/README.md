## 🚀 Getting Started

Follow these steps to run any of the projects on your local machine:

### 1. Prerequisites

Ensure you have **Python 3.x** installed. You can check by running:

```bash
python --version
```

### 2. Run a Project

Navigate to the specific project folder and execute the `main.py` script.

**Example: Running the Quiz App**

```bash
# Navigate to the directory
cd Quiz-App

# Run the python script
python main.py
```

## 💡 Learning Outcomes

By building these projects, I've practiced:

- **File Handling**: Reading/writing logs and saving application state (`open()`, `write()`).
- **Data Structures**: Using lists and dictionaries to manage app data efficiently.
- **Modular Code**: Separating logic into different files (e.g., `questions.py` in Quiz App).
- **System Interaction**: interfacing with the OS for file management and notifications.
